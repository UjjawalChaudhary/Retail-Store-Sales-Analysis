# Retail Store Sales Analysis

## Overview
This project analyzes retail store sales data using Power BI to identify sales trends, customer behavior, store performance, and profitability insights through interactive dashboards.

## Features
- Sales & Revenue Analysis
- Profit Margin & ROI Tracking
- Customer Segmentation
- Store Performance Analysis
- Product Category Insights
- Business Recommendations

## Tools Used
- Power BI
- DAX
- Excel / CSV

## Key Insights
- Identified top-performing and underperforming stores
- Analyzed customer purchasing patterns
- Evaluated product category performance
- Generated data-driven business recommendations
